Gemini Assist

Inline follow-up comment threads on gemini.google.com.

Keyboard shortcut

Opens a comment box on the current text selection. (Ctrl+H is reserved by Firefox.)

Context sent to Gemini

How much surrounding text is sent with each follow-up.

Data

Threads are stored locally, separately per conversation.

Replies use your logged-in Gemini session via an undocumented endpoint — it may need maintenance if Google changes it. For personal use.
