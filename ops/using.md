### Asking another question.

Asking another question on the same chat, minimizes all other threads and focuses the current selection and thread.
![second question](/images/another.png)

### Settings Page.

Setting pages is where you'd setup API keys. If you are logged into a chat app, the extension works even without API keys (works only on Gemini and Claude)
![settings page](/images/settings.png)

### Accessing the Settings Page.

Every conversation has a "Manage Conversation" sandwich menu on the bottom right corner.

![sandwich menu](/images/manage_conversations.png)
![click settings](/images/go_to_settings.png)
